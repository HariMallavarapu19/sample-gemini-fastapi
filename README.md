# Gemini FastAPI Chat

A simple AI chatbot API built with FastAPI and Google's Gemini API.

## Features

- FastAPI REST API
- Google Gemini integration
- Pydantic request validation
- Environment variables for API keys
- Interactive API documentation with Swagger UI

## Technologies

- Python
- FastAPI
- Google Gemini API
- Pydantic
- Uvicorn
- python-dotenv
